
# 🕷️ Spider-Man 404 Page

Página de error 404 inspirada en Spider-Man, desarrollada como proyecto académico para la carrera de Diseño y Programación Web.

El objetivo es personalizar la página de error con una propuesta visual temática y ofrecer una experiencia más atractiva cuando una página no se encuentra.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
